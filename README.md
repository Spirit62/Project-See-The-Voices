# Project See The Voices Nepal

## What It Is
A student-led website for Project See The Voices Nepal, a sign language awareness and inclusion initiative run by students. The site features a community board of student reflections, workshop documentation, and a team page.

## Why I Made It
The project needed a home that felt like it was actually made by students, and not a generic NGO template. So, I decided to go with a more fun route and made it paper themed.

## How I Made It

**Tech Stack:**
- HTML
- CSS 
- JavaScript

It was a simple website with just new designing decisions that I had never tried out like the crooked frames and just finding ideas for the paper theme.

## What I Learnt And What I Struggled With
The biggest challenge was making things look handmade without looking broken, getting the polaroid cards to work consistently across the team page took several iterations. And the solution was switching from `position: absolute` on the info strip to a natural `flex-column` layout. Managing the HTML structure across multiple contributors also led to broken nesting and duplicate IDs that had to be cleaned up repeatedly.
